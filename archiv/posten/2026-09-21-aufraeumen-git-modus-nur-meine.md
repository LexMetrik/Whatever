`npm run aufraeumen:git` kennt kein 'nur meine Flaechen' — eine Tochter-Session (D1) musste ihre eigenen Worktrees/Branches darum von Hand loeschen statt das Werkzeug zu nutzen (Reibung, Beleg .claude/notizen/archiv/2026-09-21-auswertung-mutter-tochter.md §3). Ergaenzen: ein Filter-Modus, der nur Worktrees/Branches abraeumt, die zur eigenen Session gehoeren (z. B. per Branch-Praefix/Worktree-Pfad-Muster der aufrufenden Session), damit eine Session beim eigenen Abschluss nicht versehentlich fremde, noch laufende Flaechen einer Parallel-Session beruehrt (§12).
