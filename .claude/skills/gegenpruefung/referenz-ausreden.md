# Gegenprüfung — Referenz: Ausreden und warum keine zählt

Lesen, sobald ein Red Flag des Skills zutrifft.

| Ausrede | Realität |
|---|---|
| «Ich hatte die Norm vorhin offen.» | Prüfung beginnt mit dem Öffnen in der Prüfsession. |
| «Mein Kopf-Überschlag ist das Nachrechnen.» | Unabhängiger Wert schriftlich VOR dem Vergleich, plus Randfall. |
| «Regel 1 sagt nur ‹idealerweise›.» | Das wählt das Vehikel, nicht ob geprüft wird. |
| «Scharf draufgeschaut, nichts gefunden.» | Kein Widerlegungsversuch; es zählen die drei Minimum-Punkte. |
| «Code gelesen = geprüft.» | Lesen reproduziert die Fehler des Codes. |
| «Alle anderen Tore sind grün.» | Sie prüfen Form, nie Norm-Treue. |
| «David wartet / Autonom-Modus / zu müde.» | Zeitdruck ist nie ein Verdikt-Grund; ehrlich ist: Tor bleibt rot. |
| «Artikel, Link und Stand kenne ich auswendig.» | Gedächtnis ist eine zweite Ableitung. |
| «Nur ein kleiner Fix mit einer Zahl.» | Die teuersten Bugs waren Ein-Wert-Fehler. |
| «Der Hash kippt beim nächsten Edit ohnehin.» | Der Hash findet keine Fehler; bis dahin steht der Wert live. |
| «Der Folge-Edit war trivial, ich quittiere neu.» | Der Nachweis bindet an EINEN Diff; neu quittieren ohne neu prüfen ist Token-Recycling. |
| «Nur die Quittung fehlt noch.» | Sunk Cost; fühlt sich der Durchgang zu teuer an, fehlt er. |
